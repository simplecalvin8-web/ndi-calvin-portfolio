CALVIN SIMPLE PROFESSIONAL PORTFOLIO — V4

This version keeps the black/gold reference design while adding a dedicated mobile-performance layer.

MOBILE FIXES
- Mobile navigation is touch-friendly and closes correctly.
- Canvas particles are disabled as a continuous animation on small/touch screens.
- Canvas device-pixel-ratio is capped to prevent oversized Android GPU buffers.
- Desktop cursor glow is removed on touch devices.
- Desktop 3D card tilt is disabled on touch devices.
- Portrait rings stop spinning on touch devices.
- Dust particles are reduced on mobile.
- Tap spark effects are reduced on mobile.
- Project cards become one column on very narrow phones.
- Buttons have touch-friendly hit areas.
- Modal is scrollable and fits smaller screens.
- Horizontal overflow is blocked.
- Scroll handling uses requestAnimationFrame to reduce jank.
- Background animation pauses when the browser tab is hidden.
- Reduced-motion accessibility is supported.
